# Research2025
This program tracks particles, detects their area, computes the taylor parameter, and saves the data to be analysed in real time.

V6 Local Use:
{Ensure python is installed.}
pip install -r requirements.txt or python -m pip install -r requirements.txt
python particle_tracker_April_2026.py

To create .exe file, run:
python -m PyInstaller --onefile --windowed particle_tracker_April_2026.py
